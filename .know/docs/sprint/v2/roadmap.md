## 3. 当前版本

<!-- 本版本包含/排除什么。回答"现在做什么"
  - 包含表: 每行 1 个用户可感知的能力 + 解决的问题
  - 排除列表: 明确不做的，用户语言
  - EXCLUDE: 内部模块名、存储格式、命令参数、成功指标（→ ops） -->

### 包含

| 能力 | 解决什么问题 |
|------|-------------|
| **执行数据聚合** | metrics.log 只写不读 → 跨 sprint 聚合分析 + 趋势展示 |
| **流程健康指标** | 不知道哪个阶段是瓶颈 → 阶段耗时分布 + 偏差率 + scope creep 率 |
| **生产力趋势** | 不知道自己变快了还是变慢了 → insight 展示跨 sprint 效率趋势 |

### 排除

- 可视化图表 / Dashboard
- 自动修改流程（只输出建议）
- 导出到外部系统
- 实时监控

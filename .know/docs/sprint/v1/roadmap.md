## 3. 当前版本

<!-- 本版本包含/排除什么。回答"现在做什么"
  - 包含表: 每行 1 个用户可感知的能力 + 解决的问题
  - 排除列表: 明确不做的，用户语言
  - EXCLUDE: 内部模块名、存储格式、命令参数、成功指标（→ ops） -->

### 包含

| 能力 | 解决什么问题 |
|------|-------------|
| **任务执行流水线** | agent 自由发挥容易跑偏 → 分阶段执行，每阶段有明确目标和产出 |
| **复杂度自动裁剪** | 简单任务走完整流程浪费时间 → 根据任务复杂度自动跳过不必要的阶段 |
| **方向锚点验证** | agent 执行过程中偏离目标难以发现 → 在关键节点自动校验是否偏离 |
| **长任务编排** | 大任务超出单次 agent 上下文 → 拆分为多个子 sprint 顺序执行 |
| **快速任务入口** | 小任务不需要完整流程 → 提供轻量路径直接执行 |
| **执行数据聚合** | metrics.log 只写不读 → 跨 sprint 聚合分析 + 趋势展示 |

### 排除

- 多仓库跨项目编排
- 可视化图表 / Dashboard
- 团队协作和权限管理
- GUI / Web 界面
